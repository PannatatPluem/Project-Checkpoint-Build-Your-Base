## วิธีเปิดและทดลองใช้งานเว็บไซต์ (How to Run / Test)

1. ดาวน์โหลดหรือ Clone โปรเจกต์จาก GitHub ลงในเครื่องคอมพิวเตอร์
2. เปิดโปรเจกต์ด้วยโปรแกรม Visual Studio Code
3. ติดตั้ง Extension **Live Server** ใน VS Code หากยังไม่มี
4. เปิดไฟล์ `index.html`
5. คลิกขวาภายในไฟล์ แล้วเลือก **Open with Live Server**
6. เว็บไซต์จะเปิดขึ้นบน Web Browser โดยอัตโนมัติ

### วิธีทดลองใช้งานเว็บไซต์

1. ทดลองสร้าง Portfolio ใหม่ โดยกรอกข้อมูลให้ครบถ้วน แล้วกดปุ่ม Create Portfolio
2. ตรวจสอบว่า Portfolio ที่สร้างปรากฏในรายการ Portfolio
3. เลือก Portfolio ที่ต้องการ แล้วทดลองเพิ่ม Portfolio Item
4. กรอกข้อมูลของผลงาน เช่น Title, Type, Date, Role, Description, Skills, Reflection และ Evidence
5. กดปุ่ม Add Portfolio Item เพื่อตรวจสอบว่าระบบบันทึกข้อมูลได้ถูกต้อง
6. ทดลองสร้าง Portfolio มากกว่า 1 รายการ และเพิ่มผลงานในแต่ละ Portfolio เพื่อตรวจสอบว่าข้อมูลไม่ปะปนกัน
7. รีเฟรชหน้าเว็บไซต์ (Refresh) เพื่อตรวจสอบว่าข้อมูลยังคงอยู่หลังจากปิดหรือโหลดหน้าเว็บใหม่

**หมายเหตุ:** เว็บไซต์ใช้ Local Storage ในการจัดเก็บข้อมูลบน Browser ดังนั้นข้อมูลจะถูกเก็บไว้ใน Browser ที่ใช้งาน และอาจไม่แสดงเมื่อเปลี่ยน Browser หรืออุปกรณ์
